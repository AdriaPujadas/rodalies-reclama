🚆 Rodalies Reclama

Una herramienta gratuita para registrar retrasos y preparar reclamaciones.

Datos del viaje

Por privacidad, los archivos se guardan en este dispositivo. Máximo recomendado: 1 MB por archivo.
El retraso se calcula con las horas que introduces. Esta herramienta no consulta automáticamente a Renfe/Rodalies, no determina definitivamente el derecho a compensación y no envía reclamaciones.

Consulta de avisos oficiales de Renfe

Consulta el feed público de incidencias y avisos. La hora de actualización del feed no siempre es la hora original en que Renfe publicó el aviso.

Fuente oficial y metadatos
Todavía no se han consultado los avisos.
Pulsa «Consultar avisos ahora» para intentar cargar el feed.
La fuente de Renfe incluye avisos de Cercanías de toda España. La aplicación no puede garantizar que todos los resultados pertenezcan a Rodalies de Catalunya. Los avisos se etiquetan como datos oficiales, pero la selección por palabras es solo un filtro orientativo.

Horarios teóricos oficiales

El horario completo se publica como datos GTFS estáticos, que hay que interpretar para relacionar fecha, estación, trayecto y tren. Esta versión todavía no descarga ni interpreta automáticamente ese conjunto de horarios; no sería fiable inventar una hora programada sin resolver esa correspondencia.

Mis viajes

Este historial es privado en este dispositivo y navegador. No se comparte con otros usuarios.

Control de tus datos

Los viajes y pruebas se guardan en el almacenamiento local de este navegador. No hay cuenta, servidor de usuarios ni sincronización. Otros usuarios no pueden ver tus datos desde sus dispositivos.

La copia JSON incluye los viajes y los archivos adjuntos guardados. Guárdala en un lugar privado. Exportar CSV no incluye los archivos adjuntos.

Cómo reclamar

  1. Registra las horas programadas y reales.
  2. Adjunta el billete, las capturas y otras pruebas que tengas.
  3. Guarda el viaje y genera el texto de reclamación desde el historial.
  4. Revisa y corrige el texto, adjunta las pruebas en el canal oficial y envíalo tú.
  5. Solo después de enviarlo, cambia el estado a «Enviada» y guarda el número de referencia si lo tienes.

Atención al cliente de Rodalies

Copiar el texto o abrir la web no presenta una reclamación. La aplicación no puede confirmar el envío ni la recepción.

Privacidad

Esta aplicación no requiere registro y no envía los datos del viaje a un servidor. Los datos se almacenan en el navegador de este dispositivo. Si borras los datos del navegador, usas modo privado o cambias de móvil, puedes perderlos. Haz copias de seguridad periódicas.

Al adjuntar documentos, evita compartir información personal innecesaria. Los archivos grandes pueden no guardarse por límites de almacenamiento del navegador.

Estado del servicio: proyecto independiente, gratuito y sin publicidad. No está afiliado a Renfe ni a Rodalies.
